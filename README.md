# 🦖 MiniConsole
> Công cụ cào dữ liệu và theo dõi Log thời gian thực dành cho Map Developer trong **Mini World**.

[![Download Setup](https://img.shields.io/badge/Download-Setup_v1.2.0-blue?style=for-the-badge&logo=windows)](https://github.com/Lyra-Everlyn/MiniConsole/releases/download/v1.2.0/MiniConsole_Setup_v1.2.0.exe)

---

## 🚀 Tính năng nổi bật
- **Real-time Log Monitoring:** Theo dõi và hiển thị trực tiếp dòng log từ game.
- **Auto-Update System:** Tự động kiểm tra phiên bản mới từ GitHub Releases và cập nhật trực tiếp chỉ với 1 phím bấm.
- **Giao diện Console tối ưu:** Cửa sổ dòng lệnh được cá nhân hóa với Icon riêng biệt, hỗ trợ tạo phím tắt nhanh ngoài màn hình Desktop.

---

## 📥 Tải về & Cài đặt
Bạn có thể cài đặt ứng dụng nhanh chóng bằng bộ cài tự động (Setup Wizard):
1. Tải bộ cài [MiniConsole_Setup_v1.2.0.exe](https://github.com/Lyra-Everlyn/MiniConsole/releases/download/v1.2.0/MiniConsole_Setup_v1.2.0.exe).
2. Chạy file và làm theo hướng dẫn trên màn hình để chọn thư mục lưu trữ và tạo icon ngoài Desktop.

---

## 🛠️ Cách Sử dụng (Dành cho Map Dev)
1. Đặt script Lua trích xuất dữ liệu vào môi trường Trigger của Mini World.
2. Khởi chạy **MiniConsole**, công cụ sẽ tự động bắt luồng log (`@@JSON_BATCH`, `@@OPEN_JSON`) và tiến hành biên dịch ra các file JSON hoàn chỉnh.
